to the pinned public runtime dependency. The installed package passed all 40
source/security checks, built, and passed a fresh-copy installation check. Its
compiled coordinator then rendered two six-second 1080×1920 MoviePy shorts in a
Fleet lease, validated them in a fresh worker, and confirmed cleanup. The Fleet
lease exited 0, cleaned, and restored host capacity. [Watch one output](../media/sample-short.mp4).

The `npm run demo` launcher is unit tested. This standalone verification used its
compiled coordinator entry point and an explicit image/config; it does not claim
new live runs of all three editor launchers.

MoviePy, Remotion, HyperFrames and hostile-project results. They do not establish
