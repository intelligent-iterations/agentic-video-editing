# Security

Report vulnerabilities privately to **security@intelligentiterations.com** or
through [private vulnerability reporting](https://github.com/intelligent-iterations/agentic-video-editing/security/advisories/new).
Include the affected revision and reproduction steps. Never publish credentials.

Scope includes input staging, coordinator isolation, archive handling, output
validation and cleanup. Report runtime and editor vulnerabilities to their
respective maintainers as well. The coordinator is trusted and has Docker access;
untrusted projects must never receive that connection or model credentials.

We aim to acknowledge reports within three business days.
